# ISHAMI ACCENTS — Social Commerce Web Application

A modern, mobile-first, high-converting Social Commerce Web Application for **Ishami Accents**, a curated retail home decor, smart organization, and lifestyle accessories brand based in **Kigali, Rwanda**.

Ishami Accents is the retail sister brand of **[Ishami Interior Design & Decor Ltd](https://ishamidesign.vercel.app/)**. While the parent company provides architectural interior design and custom contract furniture, **Ishami Accents** offers ready-to-ship decor pieces optimized for Instagram and TikTok traffic with instant WhatsApp checkout.

---

## 🌿 Tech Stack & Architecture

- **Framework:** Next.js 16 (App Router with Turbopack)
- **Library:** React 19
- **Styling:** Tailwind CSS v4
- **Typography:** `Cormorant Garamond` (editorial serif headings) & `Plus Jakarta Sans` (UI & body)
- **Icons:** Lucide React
- **Motion:** Framer Motion (slide drawers & micro-interactions)
- **Checkout:** Dual WhatsApp Conversion Engine (`+250 788 310 401`)
- **Timezone Engine:** Central Africa Time (CAT / `Africa/Kigali`) operating rules

## 🚚 Kigali Operating & Delivery Rules

- **Active Dispatch Days:** Monday, Tuesday, Friday, and Saturday.
- **Closed Days:** Wednesday, Thursday, and Sunday (restock, inspection & prep).
- **Delivery Guarantee:** All orders delivered across Kigali within **4 operating days**.
- **Live CAT Delivery Widget:** Dynamically calculates whether today is an active dispatch day in Kigali time and displays real-time status.

---

## 💬 WhatsApp Checkout Engine

Customers do not need credit cards:
1. **Single-Item Instant Buy:** One-click WhatsApp link on every product card with pre-filled variant and price.
2. **Slide-Out Multi-Item Bag:** Select Kigali neighborhood (Kimihurura, Kiyovu, Nyarutarama, Gacuriro, etc.), enter name, and generate an itemized WhatsApp order.

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
